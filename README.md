# Porhead / 猪头肉 / Product Portfolio

个人作品集网站，英文品牌名 `Porhead`，中文花名 `猪头肉`。  
适合 PC 端展示，版心约 `1700px`。

## 直接启动

这个文件夹已经打包好了运行环境，不需要安装 Node.js：

1. 双击 `START-PORHEAD.bat`；如果这个不生效，再试 `启动网站.bat`
2. 浏览器会自动打开 `http://127.0.0.1:8787/`
3. 关闭启动窗口即可停止本地网站

如果端口被占用，程序会自动尝试 `8787` 到 `8796`。

## 编辑模式

1. 点击右上角铅笔按钮
2. 输入密码 `ztr20720992`
3. 点击页面上的文字即可直接修改，点击图片可以上传本地图片或填写图片 URL
4. 修改会保存在当前浏览器的本机存储中
5. 点击顶部的 `退出编辑`，或再点一次铅笔按钮即可退出
6. `重置` 会清空当前浏览器的全部本地修改

编辑内容只保存在当前浏览器，换浏览器或清理浏览器数据后会恢复为原始内容。

## 开发模式

需要修改源码时，可以双击 `启动开发模式.bat`。  
文件夹内已包含 `node_modules`，也可以手动运行：

```bash
runtime\node.exe node_modules\vite\bin\vite.js --host 127.0.0.1
```

## 发布到网站

`dist` 文件夹就是已经构建好的静态网站。把它整个上传到任意静态托管服务即可，例如：

- Vercel
- Netlify
- GitHub Pages
- 阿里云 OSS / 腾讯云 COS

## 目录

```text
dist/         已经构建好的网站文件
src/          React 源码
public/       图片等静态资源
runtime/      便携版 Node.js 运行环境
START-PORHEAD.bat  双击启动成品网站（推荐）
启动网站.bat       备用的中文名启动脚本
启动开发模式.bat   双击启动开发模式
```

## 快捷键

- `空格` 或 `方向键下`：滚动到下一个模块
- `Shift + 空格` 或 `方向键上`：滚动到上一个模块
- 右侧滚动条：可以直接拖拽滚动页面
